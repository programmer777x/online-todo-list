# Online To Do List

A fast, private, offline-capable to-do list. 

This is a purely client-side web app. It requires no build step, no frameworks, and no backend. All data is saved locally in your browser using `localStorage`. It is fully installable as a Progressive Web App (PWA) on desktop and mobile.

## Features

- **Offline-first**: Works entirely offline via a Service Worker.
- **Multiple lists**: Keep separate lists for work, home, etc.
- **Sub-tasks**: Break tasks down into nested, numbered steps.
- **Section sorting**: Organize tasks into *Urgent*, *To Do*, and *To Sort*.
- **Inline editing**: Double-click any task to edit it.
- **Paste import**: Drop in multiple lines at once to add tasks in bulk (with automatic duplicate skipping).
- **JSON Import/Export**: Back up individual lists or move them between devices.
- **Themes**: Four themes (Twilight Brand, Midnight Terminal, Clean Paper, LuMi Avocado).
- **Responsive**: Desktop inline controls, mobile-friendly ⋯ action menu.
